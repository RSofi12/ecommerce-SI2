1. POLÍTICAS DE NEGOCIO Y REGLAS CLAVE INCORPORADAS
--------------------------------------------------------------------------------
1. Política de Cambio de Prenda por Talla y Precio:
   Al cambiar una prenda por otra talla o modelo (ej. Talla M a Bs 50 por Talla L a Bs 70),
   el cambio se procesa y consolida ÚNICAMENTE si el cliente paga la diferencia (Bs 20).
   Si no paga la diferencia, se cancela el cambio y se devuelve la prenda o el monto.
2. Política de Devoluciones (50% - 80% de reembolso):
   Si el cliente devuelve una prenda dentro del plazo comercial establecido, la empresa
   retiene entre el 20% y 50% por costos operativos y acondicionamiento, reembolsando
   entre el 50% y 80% del valor pagado en efectivo o nota de crédito.
3. Aportes Propios / Extras Requeridos por la Docente (Pág. 5 del pliego):
   - Extra 1: Gestión de Cambios de prendas con ajuste de diferencia por talla (CU19).
   - Extra 2: Visualización y Geolocalización de Sucursales con OpenStreetMap en Móvil (CU21).
4. Restricción Operativa Offline:
   Ventas presenciales offline obligatoriamente de contado (efectivo), con persistencia
   en IndexedDB (PWA) y SQLite (Flutter).

3. LISTA MAESTRA DE LOS 28 CASOS DE USO CLASIFICADOS POR PARCIAL Y PAQUETES

--------------------------------------------------------------------------------
PAQUETE 1: GESTIÓN DE USUARIOS, ACCESO Y MULTITENANCY
--------------------------------------------------------------------------------
CU01: Gestionar Empresas Contratantes (Tenants) [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Superadmin Plataforma, Backend
- Descripción: Alta y configuración de nuevas empresas comerciales en el modelo SaaS,
  asignando tenant_id, razón social, NIT y creando la cuenta del Administrador Tenant.

CU02: Gestionar Planes de Suscripción y Límites Comerciales [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Superadmin Plataforma, Administrador Tenant, Backend
- Descripción: Configuración y control de planes (Básico: máx. 2 sucursales; Profesional: máx. 10 sucursales
  y módulo IA). Consulta de cupos utilizados y cambio de plan.

CU03: Autenticar Usuario en Contexto Multitenant [1er Parcial - MODIFICADO]
- Plataforma: Web / Móvil
- Actores: Todos los usuarios (Superadmin, Admin Tenant, Encargado, Cajero, Cliente), Backend
- Modificación: Validación de credenciales y emisión de token JWT firmado que inyecta
  obligatoriamente los claims {tenant_id, role, branch_id}.

CU04: Gestionar Sucursales bajo Reglas de Suscripción [1er Parcial - MODIFICADO]
- Plataforma: Web
- Actores: Administrador Tenant, Backend
- Modificación: Alta de tiendas físicas validando en backend que el total de sucursales activas
  no sobrepase el límite contratado en el plan (2 o 10 sucursales).

CU05: Consultar y Actualizar Perfil de Usuario [1er Parcial - MODIFICADO]
- Plataforma: Web / Móvil
- Actores: Cliente, Empleados, Backend
- Modificación: Consulta y edición de datos personales con aislamiento estricto por tenant.

--------------------------------------------------------------------------------
PAQUETE 2: GESTIÓN DE PRODUCTOS Y CATÁLOGO AISLADO
--------------------------------------------------------------------------------
CU06: Gestionar Catálogo de Productos y Variantes por Tenant [1er Parcial - MODIFICADO]
- Plataforma: Web
- Actores: Administrador Tenant, Backend
- Modificación: Administración de categorías, temporadas, colecciones y prendas con variantes
  (SKU, talla, color, precio diferenciado), aisladas lógicamente para la empresa activa.

CU07: Consultar y Filtrar Catálogo en Línea [1er Parcial - MODIFICADO]
- Plataforma: Web / Móvil
- Actores: Cliente, Cajero / Vendedor, Backend
- Modificación: Búsqueda y filtrado multicriterio de prendas dentro del entorno del tenant.

PAQUETE 3: GESTIÓN DE INVENTARIO Y DISPONIBILIDAD MULTISUCURSAL
--------------------------------------------------------------------------------
CU08: Descargar y Almacenar Catálogo en Caché Local (IndexedDB / SQLite) [2do Parcial - NUEVO]
- Plataforma: Web PWA / Móvil
- Actores: Cajero / Vendedor, Cliente, Service Worker, SQLite Local
- Descripción: Descarga del catálogo y existencias conocidas hacia IndexedDB (web) y SQLite (Flutter)
  para garantizar la persistencia local requerida para operar sin internet.

CU09: Consultar Catálogo y Disponibilidad Local en Modo Offline [2do Parcial - NUEVO]
- Plataforma: Web PWA / Móvil
- Actores: Cajero / Vendedor, Cliente, Base de Datos Local
- Descripción: Consulta y búsqueda de productos en la base de datos local durante caídas de red,
  con indicador visual de advertencia ("Modo offline: existencias locales").

CU10: Consultar Disponibilidad de Prendas por Sucursal [1er Parcial - MODIFICADO]
- Plataforma: Web / Móvil
- Actores: Cliente, Cajero / Vendedor, Backend
- Modificación: Consulta en tiempo real de stock físico y reservado entre distintas tiendas de la cadena.

CU11: Registrar Movimiento de Inventario y Traspasos [1er Parcial - MODIFICADO]
- Plataforma: Web
- Actores: Encargado de Sucursal, Cajero, Backend
- Modificación: Entradas, salidas y traspasos de mercadería entre sucursales autorizadas de la misma empresa.

--------------------------------------------------------------------------------
PAQUETE 4: GESTIÓN DE COMPRAS, RESERVAS Y CARRITO
--------------------------------------------------------------------------------
CU12: Gestionar Carrito y Compra Digital con Pasarela Stripe [1er Parcial - MODIFICADO]
- Plataforma: Web / Móvil
- Actores: Cliente, Backend, Pasarela Stripe
- Modificación: Selección de prendas, cupones y checkout electrónico con Stripe. Despacho condicionado a pago confirmado.

CU13: Registrar Reserva de Prendas (En Línea y Offline) [2do Parcial - NUEVO / INTEGRADO]
- Plataforma: Web PWA / Móvil
- Actores: Cliente, Encargado de Sucursal, Backend, Base de Datos Local
- Descripción: Reserva de prendas con vigencia temporal para prueba en vestidor físico. Funciona con
  conexión central y también en modo offline guardándose localmente para sincronización.

CU14: Atender Reserva y Resolver Conflictos de Stock [1er Parcial - MODIFICADO / 2do Parcial]
- Plataforma: Web
- Actores: Encargado de Sucursal, Cliente, Backend
- Modificación: Separación de prendas en tienda y resolución administrativa cuando una reserva o
  venta offline sincronizada choca por falta de stock central (traspaso o cancelación).

--------------------------------------------------------------------------------
PAQUETE 5: GESTIÓN DE VENTAS, POS, CAMBIOS Y DEVOLUCIONES
--------------------------------------------------------------------------------
CU15: Registrar Venta Presencial en Caja POS (En Línea) [1er Parcial - MODIFICADO]
- Plataforma: Web / POS
- Actores: Cajero / Vendedor, Cliente, Backend
- Modificación: Cobro directo en punto de venta con emisión de comprobante y actualización de stock.

CU16: Registrar Venta de Contado en Modo Offline [2do Parcial - NUEVO]
- Plataforma: Web PWA / Móvil
- Actores: Cajero / Vendedor, Base de Datos Local
- Descripción: Cobro presencial en efectivo sin internet. Genera UUIDv4 único, descuenta stock local
  preventivo, emite ticket offline y encola la operación en estado PENDIENTE_SYNC.

CU17: Consultar Bandeja de Operaciones Locales Pendientes [2do Parcial - NUEVO]
- Plataforma: Web PWA / Móvil
- Actores: Cajero / Vendedor, Encargado de Sucursal, Base de Datos Local
- Descripción: Visualización de las ventas y reservas encoladas localmente con sus estados
  (Registrada Local, Enviada, Confirmada, En Conflicto) que sobreviven al reinicio de la app.

CU18: Sincronizar Operaciones Comerciales Locales con Idempotencia [2do Parcial - NUEVO]
- Plataforma: Web PWA / Móvil / Backend
- Actores: Cajero / Vendedor, Service Worker / Sync Manager, Backend
- Descripción: Transmisión en lote de ventas y reservas al recuperar internet. El backend valida el
  UUIDv4 en sync_audit_logs; reintentos de red no duplican ventas ni movimientos de stock.

CU19: Gestionar Cambios de Prendas con Diferencia de Precio [2do Parcial - EXTRA / APORTE]
- Plataforma: Web / POS
- Actores: Cliente, Cajero / Vendedor, Encargado de Sucursal, Backend
- Política de Negocio: Cambio de talla/modelo donde el precio varía (ej. M a Bs 50 por L a Bs 70).
  El cambio SOLO se consolida si el cliente abona la diferencia de precio (Bs 20). Si no abona,
  se rechaza el cambio y se devuelve la prenda original o se aplica devolución.

CU20: Gestionar Devoluciones de Prendas y Reembolso (50% - 80%) [2do Parcial - NUEVO]
- Plataforma: Web / POS
- Actores: Cliente, Cajero / Vendedor, Encargado de Sucursal, Backend
- Política de Negocio: Retención del 20% al 50% por costos operativos y reembolso efectivo del
  50% al 80% del valor pagado originalmente en nota de crédito o efectivo. Reintegra stock a tienda.

--------------------------------------------------------------------------------
PAQUETE 6: GEOLOCALIZACIÓN Y EXPERIENCIA VIRTUAL
--------------------------------------------------------------------------------
CU21: Visualizar Ubicación de Sucursales con OpenStreetMap [2do Parcial - EXTRA / MAPAS]
- Plataforma: Móvil (Flutter)
- Actores: Cliente, Servicio OpenStreetMap, Servicio OpenRouteService
- Descripción: Mapa interactivo en Flutter que ubica las sucursales físicas de la empresa,
  calcula distancias y muestra rutas de llegada sin depender de servicios pagos.

CU22: Usar Vestidor Virtual mediante Realidad Aumentada [1er Parcial - PRESERVADO]
- Plataforma: Móvil (Flutter)
- Actores: Cliente, Módulo AR
- Descripción: Visualización de prendas del catálogo sobre la imagen de la cámara del cliente.

--------------------------------------------------------------------------------
PAQUETE 7: INTELIGENCIA ARTIFICIAL GENERATIVA, MACHINE LEARNING Y ANALÍTICA
--------------------------------------------------------------------------------
CU23: Solicitar Reportes Generativos en Lenguaje Natural (Texto y Voz) [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Administrador Tenant, Superadmin Plataforma, Backend, Servicio LLM
- Descripción: El usuario solicita por teclado o micrófono (Web Speech API) reportes (ej. "Ventas de
  septiembre por sucursal"). Backend valida parámetros e inyecta 'WHERE tenant_id' seguro.

CU24: Presentar y Exportar Reportes Dinámicos (PDF / Excel) [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Administrador Tenant, Superadmin Plataforma, Backend
- Descripción: Renderizado dinámico de tablas y gráficos automáticos (barras, líneas, pastel)
  con controles de exportación formal a documentos PDF y hojas de cálculo Excel.

CU25: Gestionar Preparación de Datos Sintéticos para Machine Learning [2do Parcial - NUEVO]
- Plataforma: Web / Backend
- Actores: Administrador Tenant, Superadmin Plataforma, Módulo ML
- Descripción: Síntesis y preprocesamiento de dataset con variaciones estacionales para
  entrenamiento riguroso de modelos predictivos y de segmentación de clientes.

CU26: Entrenar y Evaluar Modelo Predictivo de Demanda (Supervisado) [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Administrador Tenant, Backend, Módulo ML
- Descripción: Entrenamiento de modelo de regresión/demanda para pronosticar ventas semanales
  por sucursal y categoría, apoyando la planificación de compras.

CU27: Analizar Segmentos de Clientes y Anomalías (No Supervisado) [2do Parcial - NUEVO]
- Plataforma: Web
- Actores: Administrador Tenant, Backend, Módulo ML
- Descripción: Algoritmo K-Means que descubre grupos de clientes por hábitos de compra y detecta
  desviaciones anómalas de inventario.

CU28: Consultar Cuadro de Mando y Dashboard Analítico Ejecutivo [1er Parcial - MODIFICADO]
- Plataforma: Web
- Actores: Administrador Tenant, Superadmin Plataforma, Backend
- Modificación: Tablero gerencial interactivo con KPIs de ventas, cumplimiento de stock,
  proyecciones de los modelos de Machine Learning y estado operativo de las tiendas.
